# Balance Plug 1.1.1 验证记录 — 2026-10-10

## 本次变更

- 新增默认开启且可持久保存的“是否置顶”；旧配置不含 Topmost 时沿用置顶行为。
- 导入静态 PNG 之前可填写形象名称，确定后保存，取消不改变图库和当前选择。
- 当前本地形象提供重命名入口；重名自动编号、空白／超长／控制字符拒绝、重复图片不新建条目，可更新名称。
- 重命名保存失败时恢复原名称；图片哈希、文件内容、选择和会话不变。
- 版本为 1.1.1，独立发布，未覆盖运行中的 1.1.0 目录。

## 已验证

- Release 构建 0 警告、0 错误。
- 44 项核心自动测试通过，包含原有接口、迁移、动画差额模型及新增置顶默认／持久保存、更名、去重、保存失败回滚测试。
- 137 项窗口断言通过，包括主窗口原生 WS_EX_TOPMOST 开／关、菜单保持与勾选同步、名称显示、重命名入口和命名弹窗的空白校验／取消／确认。
- 命名弹窗沿用圆角主题，渲染预览经过查看，未发现输入框或按钮裁切。
- 最终窗口回归单独运行通过；中间并行的窗口测试曾因共享桌面焦点失焦而关闭菜单，未将该失败轮次计作通过。

## 本次没有宣称通过的项目

- 原生实际鼠标点击仍待用户现场检查；控件管线断言不能代替硬件鼠标操作。
- 本次未重新测量性能，不沿用旧版测试值冒充 1.1.1 实测；1.1 的热点界面后内存超出 100 MB 和其他待验收项仍见 docs/VERIFICATION-v1.1.md。
- 多显示器／不同 DPI／睡眠唤醒／实际自启及两小时稳定性未补验。

## 更新方式

先从旧版菜单关闭程序，再打开 publish-v1.1.1/BalancePlug.exe。原图片库、会话和独立大小设置保留；自启如指向旧目录，取消再勾选以更新路径。

测试全部使用隔离临时配置，没有修改正常用户配置或登录会话；未强制退出当前 1.1.0 进程。
