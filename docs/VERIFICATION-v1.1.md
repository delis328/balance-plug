## 阻塞／尚未完成

- **实际鼠标操作验收未完成**：原生截图接口返回 SetIsCursorCaptureEnabled failed: 不支持此接口 (0x80004002)，无截图读取辅助功能后，真实点击仍返回 coordinate input geometry is unavailable。已做一次恢复尝试，未绕过工具另造输入驱动。
- 因此尚不能确认真实悬浮窗右键、任务栏图标右键、菜单内实际鼠标连续选择／空白点击、外部点击关闭、真实滑杆拖动和跨应用穿透；窗口管线与键盘测试不计作这些项目的通过。
- 100%／150%／200% DPI、多显示器、睡眠唤醒、实际自启及至少两小时连续稳定性尚待现场验证。
