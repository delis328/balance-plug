# Balance Plug 1.2.1 验证记录

## 本次修复

- 金额背景由文本尺寸测量的真椭圆绘制，不再拉伸为固定容器宽度。
- 透明弹出层为起点至终点的完整轨迹预留空间，金额气泡沿线性动画持续移动，末段淡出，不被弹出 HWND 裁切。
- 可视路径编辑：左侧淡红区域顺序点击出现点、上方目标点；支持拖动微调，虚线和标签同步。路径映射到主余额气泡左侧区域。
- 预览按钮显示演示金额，不调用 API 或改变余额基准；速度、大小与路径可独立设置。
- 旧坐标保留；打开编辑器后可重新选择两点，恢复默认同步滑杆与路径。

## 已完成验证

- Release 构建 0 警告、0 错误；46 项核心测试、75 项窗口断言通过。
- 新增真椭圆检查、文本贴合宽度、多帧连续向上、完整轨迹绘制范围、两点编辑与可见路径线一致、设置控件无裁切断言。
- 椭圆提示和路径设置窗口的渲染预览已查看；余额为演示值，不是实时截图。
- 原生实际鼠标操作尚需用户现场确认；程序化点选择、布局与多帧动画断言不冒充硬件鼠标验收。
- 按用户要求未进行性能测试；热点内存和长期稳定性优化保留到后续。
