# Balance Plug 1.3.0 验证记录

## 变更

- 查询 /api/v1/usage/stats 的 total_actual_cost，标准费用 total_cost 不用于提醒。
- 固定 Asia/Shanghai 时区，start_date 与 end_date 均为当日；服务端结束日期按包含当日处理，统计为北京时间 00:00 至次日 00:00。
- 双击吉祥物切换辅助行今日花费／更新时间，余额大金额保留；拖窗改为移动超过系统阈值后触发，避免抢走双击。
- 提醒默认关闭、阈值默认 20 美元；超过 T 首次，之后 T+5、T+10…美元提醒。
- 每轮跨多个节点只显示一次，随机从勾选文本中取一条，10 秒后恢复辅助行。当天已提醒节点持久保存，跨日／账户／阈值变更重置。
- 保存提醒节点失败不显示无法去重的提醒；查询失败保留同日旧值并标记失败，跨日清除昨日数字。
- 午夜使用一次定时安排，不每秒轮询；唤醒时重新核对日期。

## 验证

- Release 构建零警告零错误；56 项核心测试、78 项窗口断言通过。
- 核心覆盖北京时间午夜、精确日期和时区参数、实际费用字段、坏响应、认证刷新、阈值边界、五美元节点、跨节点、重启序列化、跨账户、禁用／未选文本和阈值编辑。
- 窗口检查提醒替换辅助文本、保留余额、10 秒恢复今日花费、同节点不重提醒及设置窗口渲染。
- 提醒设置窗口渲染已经视觉查看并修复保存按钮裁切。
- 使用本机已有授权会话只读核对站点统计返回字段，未输出凭据或实际金额，未修改正常会话文件。
- 未进行性能测试或两小时长测。真实鼠标双击、日期现场切换和真实业务金额变化仍需用户现场确认，不由控件测试冒充。

## 交付

独立目录 publish-v1.3.0；压缩包不含账号、会话、个人图片和测试数据。先退出旧版再启动新版本。设置入口为“今日花费提醒…”，勾选启用、填写美元阈值、添加并勾选提示文本，保存后生效。

旧版本目录未覆盖，源码修改、CHANGELOG 和验证记录保留在工作区；本次未自动提交或推送 GitHub。
